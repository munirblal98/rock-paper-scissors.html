# Rock Paper Scissors Game

A browser-based Rock Paper Scissors game developed using HTML, CSS, and JavaScript. The game allows users to play against the computer with instant result generation and score tracking.

## Technologies Used

* HTML
* CSS
* JavaScript

## Features

* User vs Computer gameplay
* Random computer choice generation
* Live result display
* Score tracking system
* Interactive and responsive interface

## Purpose of the Project

This project was developed to strengthen understanding of JavaScript logic building, conditional statements, randomization, and DOM interaction.

## What I Learned

* JavaScript game logic
* Conditional statements and functions
* Random number generation
* DOM manipulation
* Interactive UI development
